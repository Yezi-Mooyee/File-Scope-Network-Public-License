This is the project homepage for the FSNPL (File-Scope Network Public License).

This license attempts to design a more permissive open-source license based on the MPL, but without the SaaS loophole.

Currently, this license is merely a private license drafted by AI; it has not been published, certified, or officially endorsed. It attempts to offer a middle-ground possibility: not as highly restrictive as the AGPL, yet without the SaaS loophole found in the MPL.
